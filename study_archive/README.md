# Reference code for decision tests

`frozen_core/` holds the August 30 code used to compare decisions under supplied
posteriors. These tests do not fit GPs or regenerate study trials.

Install the maintained package using the [README](../README.md). Saved trial
records are in [`results/`](../results/), with later analyses in
[`paper/revision_analysis/`](../paper/revision_analysis/).

The full historical source, original environments and calibration path shards
are kept separately. Public archive access and a persistent identifier remain
to be arranged. See [Reproduction](../docs/reproducibility.md) for what this
checkout can reproduce.
