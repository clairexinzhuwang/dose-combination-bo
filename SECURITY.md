# Reporting software issues

For a security-sensitive issue, contact `xinzhu_wang@urmc.rochester.edu`
privately. Include the software version, operating system and a small example
that shows the problem. Leave out credentials, patient data and confidential
material.

For ordinary software or documentation problems, use the
[issue tracker](https://github.com/clairexinzhuwang/dose-combination-bo/issues).
